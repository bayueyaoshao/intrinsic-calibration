# 相机内参标定与评估框架

输入预先采集好的标定图像,输出当前数据条件下**可论证为最优**的相机内参,以及完整的证据链报告。

## 最优的三条判据(同时达标)

1. 留出验证(held-out)泛化误差最小——用没见过的照片考试,而不是死记训练照片;
2. 参数稳定——换一批子集重标,内参不乱跳;
3. 误差逼近 CRLB 理论下界(CRLB = 克拉美-罗下界:任何无偏估计方法的误差都不可能低于它,用来回答"这批数据天生最准能到多少")。

## 快速上手

```bash
uv sync                # 安装依赖(锁文件 uv.lock 已提交,版本固定)
uv run calib --help    # 九个子命令 = 整条流水线的通俗中文地图
uv run calib ingest    # 第①步:照片入库体检,产出数据清单 manifest.json
```

目录约定:

- `input_data/train|test` — 只读输入(同一台相机、相同拍摄参数)
- `config/` — 标定板规格(board.yaml)与全部算法参数(calibration.yaml),换数据集只改这里
- `output/` — 运行产物(不进 git),每轮按时间戳分目录留痕、可追溯

## 流程总览

八步流水线:① 照片入库体检 → ② 找棋盘角点 → ③ 测噪声底 → ④ 求解相机内参
→ ⑤ 算理论精度极限 → ⑥ 防作弊考试 → ⑦ 误差归因 → ⑧ 汇总证据出报告。

带流程图与阶段契约的完整说明见 `docs/pipeline.md`。

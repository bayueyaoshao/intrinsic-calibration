## Fisher 观测集口径

### Q1: FIM 的观测集用什么口径?

| Option | Description | Selected |
|--------|-------------|----------|
| 640 正式 + 80 对照(推荐) | 正式结论用 640 全帧(与阶段四实际标定同口径,与 OpenCV stdDev 交叉验证天然对齐);80 姿态聚合版一并算出对照。两版差值=「连拍相关性吃掉多少信息」 | ✓ |
| 80 独立姿态口径 | 每姿态 8 连拍角点取均值当一帧,FIM 按 80 视图算。统计最诚实,但与阶段四实际标定口径不同 | |
| 只算 640 全帧 | 实现最简,但丢掉「相关性损耗」这个量化发现 | |

**User's choice:** 640 正式 + 80 对照

### Q2: 80 姿态对照版的每姿态角点聚合方式?

| Option | Description | Selected |
|--------|-------------|----------|
| 逐点均值(推荐) | 同姿态 8 连拍角点逐点取平均,噪声理论降 √8。PROJECT.md 里原本的候选就是均值聚合 | ✓ |
| 逐点中位数 | 抗单帧离群,但均值意义下不是最优估计 | |
| 最清晰一帧 | 用体检清晰度分数选同姿态最清晰一帧的角点,不聚合,保守 | |

**User's choice:** 逐点均值

## σ 口径:喂给 CRLB 的噪声

### Q1: 进 FIM 的 Σ 用什么口径?

| Option | Description | Selected |
|--------|-------------|----------|
| 双口径并排(推荐) | 检测器口径(Immerkaer 像素噪声经传递曲线折算)= 理论主线;时域总波动口径(含位姿抖动)= 实际预期主线。两套 CRLB 并排,各配 ±27% 敏感性带 | ✓ |
| 仅检测器口径 | 纯 iid 高斯假设最干净,与 stdDeviationsIntrinsics 交叉验证最对齐,但漏掉位姿抖动 | |
| 仅时域总波动 | 与阶段四重复张分组实测直接可比,但不是教科书意义的 CRLB | |

**User's choice:** 双口径并排

### Q2: Σ 的形状怎么定?

| Option | Description | Selected |
|--------|-------------|----------|
| 标量主线+逐角点对照(推荐) | 正式 CRLB 与交叉验证用标量 σ(每口径一个数);连拍逐点波动直接给出的逐角点 σ(88 个)一并落盘作诊断对照,不进正式 FIM | ✓ |
| 仅标量 | 最简单,丢掉「哪些角点更抖」的空间信息 | |
| 逐角点加权进 FIM | 最精细,但与 OpenCV 同方差假设偏离,交叉验证口径变复杂 | |

**User's choice:** 标量主线 + 逐角点对照

## 线性化点与模型范围

### Q1: CRLB 对哪些模型算?

| Option | Description | Selected |
|--------|-------------|----------|
| 全 4 模型并排(推荐) | M1–M4 各出一份 CRLB 并排落盘。沿用阶段二「全矩阵多存」风格,阶段四选型时直接引用 | ✓ |
| 仅 M2 | 最省,但阶段四选型若翻盘要回头补算 | |
| 仅针孔族 M1–M3 | M4 鱼眼暂不参与(其收敛稳定性待阶段四验证) | |

**User's choice:** 全 4 模型并排

### Q2: 每模型的 FIM 线性化点取哪条求解路径的结果?

| Option | Description | Selected |
|--------|-------------|----------|
| scipy linear 精化点(推荐) | 每模型用其无鲁棒核的 scipy 精化结果(mX__scipy):高斯假设下的经典 CRLB 推导本就对应无加权极小点,口径最纯正 | ✓ |
| softl1 精化点 | 与阶段四最终可能采用的鲁棒标定更接近,但等效权重让经典 FIM 公式口径变复杂 | |
| 研究阶段定 | 含「换点重算一次验证不敏感」检查 | |

**User's choice:** scipy linear 精化点

### Q3: FIM SE 与 OpenCV stdDeviationsIntrinsics 交叉验证的范围怎么定?

| Option | Description | Selected |
|--------|-------------|----------|
| M1/M2 硬性+M3 尽力(推荐) | M1、M2 硬性对齐到个位数百分比;M3(有理模型)尽力对齐,对不上则按发现记录不阻塞;M4 记录「OpenCV 无可比输出」结论 | ✓ |
| M1–M3 全部硬性 | 风险:OpenCV 有理模型 stdDev 若有坑会卡成功标准 | |
| 仅 M2 | 最省;成功标准原文未限定模型数 | |

**User's choice:** M1/M2 硬性 + M3 尽力 + M4 记录结论

## 传递曲线注入实验规模

### Q1: 注入实验在真实图像上加噪重跑检测器,规模多大?

| Option | Description | Selected |
|--------|-------------|----------|
| 全量 640 张(推荐) | 经验最充分,顺带产出「哪些姿态/区域对噪声更敏感」的全量数据。并行后估计十几分钟到小时级,符合「算力便宜多存」风格 | ✓ |
| 抽样 80 张 | 每姿态抽 1 张,分钟级出曲线;曲线粒度够用但丢了逐姿态敏感度信息 | |
| 先小规模后补 | 曲线只在少量图上标定形状;后续阶段发现不够准再扩规模 | |

**User's choice:** 全量 640 张

### Q2: σ 档位网格与重复次数怎么定?

| Option | Description | Selected |
|--------|-------------|----------|
| 研究定网格+每档重复 3–5 次(推荐) | 档位密度与上限由研究阶段定(覆盖实测 Immerkaer σ 邻域+延伸到检测器失效点,对数网格约 7–8 档);每档重复 3–5 次压随机性 | ✓ |
| 密网格 | 12+ 档追求曲线平滑,运行时间翻倍;曲线形状不是本阶段交付重点 | |
| 稀网格 | 3–4 档只保插值够用;但检测器失效点可能标不准 | |

**User's choice:** 研究定网格 + 每档重复 3–5 次

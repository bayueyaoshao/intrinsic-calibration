## 废帧体检判定与剔除方式

### Q1 体检发现疑似废帧后,第一版怎么处置?

| Option | Description | Selected |
|--------|-------------|----------|
| 全自动剔除留痕(推荐) | 体检结论直接生效,标定自动跳过废帧,manifest 留痕可查;同姿态 8 张连拍,废几张不伤标定,第一版最简 | |
| 分级处置 | 找不到棋盘=自动废;模糊/曝光边缘存疑的只标记,复核清单后手动确认 | |

### Q3 模糊度/曝光两项指标的存疑判定用什么基准?

*(提问时用户要求先解释——解释了三种基准的含义与利弊后重问)*

| Option | Description | Selected |
|--------|-------------|----------|
| 连拍内相对比较 | 同姿态几张连拍互相比,明显差的标存疑;天然比例化,但单张姿态没参照 | |
| 全局比例化阈值 | 所有照片一把尺(按棋盘占比等归一),阈值写在 config 可调 | |

**User's choice:** 两者结合
**Notes:** 用户先要求解释题目;解释"分数只是数字,判定需要参照物"及三方案后选择。

## 基线标定用哪个模型

### Q1 第一版基线标定跑哪些模型?

| Option | Description | Selected |

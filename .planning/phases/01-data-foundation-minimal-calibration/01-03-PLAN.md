  calibrate_fisheye(image_points_per_view, image_size, board, cfg) —— cv2.fisheye.calibrate:K=np.eye(3)、D=np.zeros(4) 交由其内部初始化(文档默认:cx,cy 置图像中心,焦距按 max(宽,高)/π 最小二乘初始化);flags 从 config 读(默认 0 = 估计 skew,显式记录进产物,不要凭记忆写"默认固定 skew"——研究已修正过这个错误笔记);终止条件 (EPS+COUNT, cfg.max_iter=100, cfg.epsilon=1e-6);物点与角点每视图显式 reshape (88,1,3)/(88,1,2) float64(Pitfall 5,进函数先断言形状);整体 try/except cv2.error,失败返回 dict(converged=False, failure_note=中文含异常信息, K=None, D=None, rms_overall=None, per_view_rms=None)——失败值语义就此定死:数值字段为 None、落盘成 JSON null,结构键一个不少——KB4 对非鱼眼广角数据可能 Ill-conditioned,这是 D-10 预期内的正常发现,记录不崩。

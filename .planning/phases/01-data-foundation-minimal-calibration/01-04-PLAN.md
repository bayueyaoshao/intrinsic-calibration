  <action>
  src/calib/io/precheck.py:compute_metrics(gray, cols, rows, cfg) 返回指标 dict,三个指标——
  模糊度:board_roi(gray, cols, rows) 先用 cv2.findChessboardCorners + CALIB_CB_FAST_CHECK 作预筛定位棋盘检测框(FAST_CHECK 只作预筛加速,失败时回退完整检测,再失败用全图并标记 roi_found=False);blur_raw = cv2.Laplacian(gray_roi, cv2.CV_64F).var()(拉普拉斯 = 二阶差分,锐利边缘响应大,值越小越糊);归一值 blur_norm = blur_raw / sq_px²(边缘锐度能量随方格像素边长平方缩放,sq_px 取检出角点经 estimate_sq_px 的值;未检出棋盘时 blur_norm 记 NaN 并在 visibility 里体现)。整图拉普拉斯方差依赖背景与分辨率,棋盘框内计算把度量锚定在标定真正在乎的区域——这是比例化的第一层。
  曝光:exposure_clip(gray) 返回 (高光裁剪比例 = 灰度 >= 250 的像素占比, 阴影裁剪比例 = <= 5 的占比),百分比天然比例化,在全图上算(JPEG 8 位 0–255)。
  棋盘可见性:visibility_probe(gray, cols, rows, cfg) 调经典(findChessboardCorners,ADAPTIVE_THRESH+NORMALIZE_IMAGE)与 SB(findChessboardCornersSB)各一次,记录 classic_ok / sb_ok 布尔、box_area_ratio(棋盘检测框面积 / 图像面积,比例化)、corners_count_ok(检出且恰为 cols*rows 个角点)。探针不做 cornerSubPix、不做规范化——体检只问"看没看见",精化是角点阶段的事。
  tests/test_io_precheck.py:合成清晰棋盘图 vs GaussianBlur 强模糊版,blur_raw/blur_norm 方向正确(模糊版显著更低,比值断言如 < 1/3);像素截断到 250+ 的过曝图 exposure_clip 高光比例 > 0.3,暗图(像素压到 <=5)阴影比例 > 0.3;纯噪声图(无棋盘)visibility_probe 双 False 且 corners_count_ok False;board_roi 对无棋盘图回退全图不抛异常。
  </action>

  verdict 规则:verdict = "suspect" 当且仅当 suspect_sources 非空,否则 "ok";任何情况下不产生"剔除"动作,存疑照片照常留在数据流中(D-01 行为锁定:函数连"剔除"这个概念都没有,只有标记)。
